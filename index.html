Conecta este dispositivo

Para guardar cambios, Sintonía necesita un permiso de GitHub. Se pide una vez en cada navegador y queda guardado solo en él.

  1. Abre GitHub para crear el permiso.
  2. En Repository access elige Only select repositories y marca sintonia.
  3. En Permissions, comprueba que Contents está en Read and write.
  4. Pulsa Generate token, copia el código y pégalo aquí.
